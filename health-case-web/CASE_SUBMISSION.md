# 病例资料提交

当前功能范围是填写病例信息并提交 PDF 或图片：

- 必填患者姓名、病例名称、病例描述（5至2000字），并从「我的保单」选择一张保单。服务端以登录手机号匹配投保人或被保人手机号。
- 可只提交 PDF、只提交图片，或混合提交；每次1至9个文件，单个不超过10MB。
- 支持 PDF、JPEG、PNG、GIF、WebP，后端检查文件头、MIME、数量及大小。文件头检查用于识别类型，不代表完整解析或内容审核。
- 病例与附件信息写入原有 service_record、service_record_image 表，保单关联写入现有的 service_record.policy_id。管理端案件详情展示所绑定的保单。
- 文件保存到已有 OBS 私有桶；查看详情时生成签名链接。图片可以放大查看，PDF 可单独打开。链接失效时刷新详情重新获取。
- 上传失败会回滚病例数据，并尝试清理本次上传对象；提交结果未知时保留对象供核对。
- ui 界面轮播仍只接受图片，不能上传 PDF。

运行前按 CONFIGURATION.md 配置真实数据库和 OBS；原有病例相关业务表必须已经存在，自动建表仅适用于此前新增的 ui 表。

提交接口为 POST /api/service-record/save（multipart/form-data）。字段包括 name、policyId、caseTitle、caseDescription、可选 visitDate 和重复的 files 文件字段。联系电话由登录会话确定。提交前需要建立用户登录会话。

用户端为同一份表单及附件复用 requestId。该值是 32 位小写十六进制标识。提交响应丢失时重试原内容，会返回已经创建的案件 ID。相同登录手机号及标识对应不同内容时返回 409。旧客户端仍可省略该字段。

自动化测试源码已按要求移除；真实数据库和 OBS 联调需在相应环境配置后进行。
